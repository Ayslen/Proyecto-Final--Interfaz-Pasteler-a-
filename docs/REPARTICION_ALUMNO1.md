# Repartición del Proyecto Final

## Alumno 1: Backend, Login y Roles de Usuario

El Alumno 1 se encarga de la estructura principal del sistema y del acceso de usuarios.

## Responsabilidades cubiertas en este código

- Crear la estructura inicial del proyecto.
- Configurar la conexión general del sistema.
- Crear el sistema de login.
- Crear el registro de usuarios.
- Implementar roles de usuario:
  - Admin
  - User
- Proteger páginas según el rol.
- Crear cierre de sesión.
- Redirigir al usuario según su tipo de cuenta.
- Validar que los usuarios no se repitan.
- Guardar contraseñas con hash.

## Empresa simulada

- Empresa: pastelería industrial.
- Producto: pasteles y postres empaquetados.
- Materia prima: harina, azúcar, huevos, leche, mantequilla, crema, chocolate, frutas, levadura, colorantes y empaques.
- Producción: elaboración diaria de pasteles, cupcakes, galletas y postres para venta al público o distribución.
